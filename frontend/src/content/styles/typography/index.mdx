The correct typeface should be used when creating a GOV.UK or an i.AI product. Everything else about type, including the type scale, heading levels and spacing, is the same for both.

> You do not need to apply this guidance yourself. It's already built in when you start a project using the agent skill file or i.AI cookie cutter template. Get started

## Typeface

If you're building a GOV.UK product, use GDS Transport, with the official GOV.UK Design System fallback stack. If you're building an i.AI product, use Inter, with Helvetica and Arial as fallbacks.
