## When to use this component

Use the table component to let users compare information in rows and columns.

## When not to use this component

Never use the table component to layout content on a page. Instead, use the [grid system](https://design-system.service.gov.uk/styles/layout/#using-the-grid-system).
## Component options

These are the same for Astro, React, Svelte and Solid.

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `subtle` | boolean | No | Adds the subtle style, to reduce the table's prominence when it is not the main focus of the page. |
| `smallTextUntilTablet` | boolean | No | Uses smaller text on screens narrower than a tablet. |
| `summary` | boolean | No | Uses the compact summary layout, with vertically centred cells and tighter padding. |
| `children` | text | Yes | The table content, with the rows grouped in a head and a body. |
| `class` | text | No | Adds extra classes to the table. |
