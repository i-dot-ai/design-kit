## Default

The default details component reveals more detailed information when the summary is activated.

<Example optionsHref="#component-options" component="details" html="./examples/default.html" astro="./examples/default.astro" react="./examples/default.react.tsx" svelte="./examples/default.svelte" solid="./examples/default.solid.tsx" webComponents="./examples/default.web-components.html" />

## When to use this component

Use the details component to make a page easier to scan when it contains information that only some users will need.

## When not to use this component

Do not use the details component to hide information that the majority of your users will need.

## Component options

These are the same for Astro, React, Svelte and Solid.

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `open` | boolean | No | Set to show the details content when the page loads. |
| `class` | text | No | Additional classes on the `details` element. |
| `children` | text | Yes | The summary and the revealed content. |
