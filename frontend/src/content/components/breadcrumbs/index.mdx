## When to use this component

Use the breadcrumbs component when you need to help users understand and move between the multiple levels of a website.

## When not to use this component

Do not use the breadcrumbs component on websites with a flat structure, or to show progress through a linear journey or transaction.

If you’re using other navigational elements on the page, such as a sidebar, consider whether your users need the additional support of breadcrumbs.

## Component options

These are the same for Astro, React, Svelte and Solid.

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `inverse` | boolean | No | Adds the `govuk-breadcrumbs--inverse` modifier, for use on dark backgrounds. |
| `collapseOnMobile` | boolean | No | Adds the `govuk-breadcrumbs--collapse-on-mobile` modifier, which hides all but the last crumb on small screens. |
| `class` | text | No | Additional classes on the `nav` element. |
| `children` | text | Yes | The breadcrumb items. |
