## Line

A line chart shows how values change over an ordered range, such as time. The data is always in a table, so it can be read without JavaScript and by screen readers.

<Example component="chart" html="./examples/line.html" />

## When to use this component

Use a chart when the shape of the data matters more than the exact values, for example a trend over time or a comparison between a few series.

Use colours from the [chart colours](/styles/chart-colours). Do not use colour as the only way to tell series apart: give each series a clear label and a different line style (solid, dashed or dotted).

## When not to use this component

Do not use a chart if users need to read or compare exact values. Use a [table](/components/table) instead.
