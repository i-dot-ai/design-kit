## When to use this component

Use a chart when the shape of the data matters more than the exact values, for example a trend over time or a comparison between a few series.

Use colours from the [chart colours](/styles/chart-colours). Do not use colour as the only way to tell series apart: give each series a clear label and, on line and area charts, a different line style (solid, dashed or dotted).

## When not to use this component

Do not use a chart if users need to read or compare exact values. Use a [table](/components/table) instead.

Only use a pie or doughnut chart for a few parts of one whole, ideally no more than five. People find it hard to compare the size of slices, so a bar chart is usually clearer.

## Horizontal bar

A horizontal bar chart compares values across categories, with each value shown at the end of its bar. Use it when category names are long or there are many categories. Keep it to one or two series so the values stay readable. If the bars get too thin for their values, the values are hidden; they are still in the table.

## Pie

A pie chart shows how a whole splits into parts. It uses the first data column only. Each slice is labelled with its name and value; on narrow screens, or with more than 6 slices, a legend is used instead. Slices follow the categorical colour order. You can [change the colour](#changing-the-colour) of each slice.

## Adding a description

Add a description to say what the chart shows in a sentence or two, for example the main trend or the biggest value. It appears under the title, and screen readers read it with the chart.

The title is an `h3` by default. Change the heading level so it fits the headings on your page. See the [component options](#component-options).

## Formatting values

By default, values are shown as en-GB numbers. Set `format` to show them another way, for example as times. The format is used in the data table, on the axes, in tooltips and in value labels.

<Example component="chart" optionsHref="#component-options" html="./examples/line-format.html" react="./examples/line-format-function.react.tsx" svelte="./examples/line-format-function.svelte" solid="./examples/line-format-function.solid.tsx" />

Formatting works differently in HTML. It takes [`Intl.NumberFormat` options](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/NumberFormat#options), which can only show one unit, such as "62.1 mins", not "1h 2m 3s". This is why the HTML examples give their values in minutes. React, Svelte and Solid take a function, so they can show any format. If you need a format that `Intl.NumberFormat` cannot show, use one of the framework components.

## Changing the grid lines

Line, area and bar charts show only horizontal grid lines by default, and horizontal bar charts only vertical ones: the grid lines follow the value axis.

This is based on [guidance from the ONS on grid lines](https://service-manual.ons.gov.uk/data-visualisation/guidance/axes-and-gridlines#gridlines). which states that grid lines should not be used on time or for discrete categories. It is assumed that line graphs will have time values on the x axis and bar charts will have discrete categories. If this is not the case, you should update the grid lines to be on the relevant axis.

Set `gridLines` to draw different lines. `horizontal` and `vertical` name the lines themselves, not the axes. In plain HTML, set `data-iai-chart-grid-lines` on the chart instead. The option is ignored on pie and doughnut charts. See the [component options](#component-options).

## Changing the size

Line, area, bar and horizontal bar charts fill the width of their container. Pie and doughnut charts are square, so they stop at 600px wide. You can change this maximum width, or remove it. See the [component options](#component-options).

## Accessibility

### Colour

Do not rely on colour alone. Some people cannot tell colours apart.

- Use colours from the [chart colours](/styles/chart-colours) palette. They are chosen to work together.
- Give each series and slice a clear label.
- Charts with only one series or slice have no legend, so make sure the title says what it shows.
- Use no more than 5 colours in one chart.

### Line styles

On line and area charts, give each series a different line style: solid, dashed or dotted. People can then tell the lines apart without seeing colour, including when printed in black and white.

Bar, horizontal bar, pie and doughnut charts cannot use line styles. Keep these to a few series or slices, and label them clearly.

### Data table

Every chart includes its data as a table, under "Show data".

- Screen readers announce the chart's title and description, and users can open the table to read the values.
- If JavaScript does not load, the table is still there.
- Users can read exact values that are hard to judge from the chart.

## Component options

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `variant` | `"line"`, `"area"`, `"bar"`, `"horizontal-bar"`, `"pie"` or `"doughnut"` | Yes | The type of chart. |
| `title` | text | Yes | Shown as the heading and the table caption. Screen readers read it as the chart's name. |
| `description` | text | No | A short summary of what the chart shows. Shown under the title, and screen readers read it with the chart. |
| `headingLevel` | `1` to `6` | No | The title's heading level. Defaults to `3`. |
| `data` | object | Yes | The chart's data. See below. |
| `format` | function, or `Intl.NumberFormat` options | No | Formats values in the table, on the axes, in tooltips and in value labels. In React, Svelte and Solid, a function that takes a value and returns text. In HTML, `Intl.NumberFormat` options. |
| `showNullValuesAsZero` | boolean | No | Plots `null` values as 0 so a line stays unbroken instead of leaving gaps. The data table still shows `–` for those values. Intended for line and area charts. In plain HTML, an empty `data-iai-chart-show-null-values-as-zero` attribute. |
| `gridLines` | `"horizontal"`, `"vertical"`, `"both"` or `"none"` | No | Which grid lines to draw. `horizontal` and `vertical` name the lines themselves, not the axes. Defaults to the lines along the value axis: horizontal on line, area and bar charts, vertical on horizontal-bar. Ignored on pie and doughnut charts. In plain HTML, a `data-iai-chart-grid-lines` attribute. |

### `data`

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `heading` | text | Yes | The header of the table's first column, which names the labels. For example, "Month". |
| `labels` | list of text | Yes | The points along the axis, or the slices of a pie. For example, `["January", "February"]`. |
| `datasets` | list of datasets | Yes | One for each series. Pie and doughnut charts use the first dataset only. |

### Each dataset

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `label` | text | Yes | The series name, shown in the legend and as the table column header. |
| `data` | list of numbers | Yes | One value for each label, in the same order. Use `null` to leave a gap. |
| `colour` | a [chart colour](/styles/chart-colours) name, or a list of them | No | One colour for the series. On pie and doughnut charts, a list with one colour for each slice. If not set, colours follow the default order. |
| `line` | `"solid"`, `"dashed"` or `"dotted"` | No | The line style, on line and area charts. If not set, line styles follow the order solid, dashed, dotted. |

### HTML

In plain HTML, set the same options on the markup:

| Option | Where | Example |
| --- | --- | --- |
| Chart type | A class on the outer `div` | `class="iai-chart iai-chart--pie"` |
| Description | A paragraph after the heading | `<p class="govuk-body iai-chart__description">` |
| Heading level | The heading element | `<h2 class="govuk-heading-m">` |
| Series colour | An attribute on the column header | `<th data-iai-chart-colour="blue-shade-50">` |
| Slice colour | An attribute on the row header | `<th scope="row" data-iai-chart-colour="blue">` |
| Line style | An attribute on the column header | `<th data-iai-chart-line="dashed">` |
| Value format | `Intl.NumberFormat` options as JSON, on the outer `div` | `data-iai-chart-format='{"style":"unit","unit":"minute"}'` |
| Null values as zero | An empty attribute on the outer `div` | `data-iai-chart-show-null-values-as-zero` |
| Grid lines | An attribute on the outer `div` | `data-iai-chart-grid-lines="both"` |
| Values | The table cells, as numbers | `<td>1,240</td>`. Use `–` or leave empty for a gap. If the text is not the number, add the number in a `data-value` attribute, for example `<td data-value="12.4">12.4 mins</td>`. |
| Maximum width | The `--iai-chart-max-width` CSS variable, on the chart or a container, for pie and doughnut charts. Use `none` to remove the limit | `style="--iai-chart-max-width: 400px"` |
