## When to use this component

Use a chart when the shape of the data matters more than the exact values, for example a trend over time or a comparison between a few series.

Use colours from the [chart colours](/styles/chart-colours). Do not use colour as the only way to tell series apart: give each series a clear label and, on line and area charts, a different line style (solid, dashed or dotted).

## When not to use this component

Do not use a chart if users need to read or compare exact values. Use a [table](/components/table) instead.

Only use a pie or doughnut chart for a few parts of one whole, ideally no more than five. People find it hard to compare the size of slices, so a bar chart is usually clearer.

## Horizontal bar

A horizontal bar chart compares values across categories, with each value shown at the end of its bar. Use it when category names are long or there are many categories. Keep it to one or two series so the values stay readable. If the bars get too thin for their values, the values are hidden; they are still in the table.

## Pie

A pie chart shows how a whole splits into parts. It uses the first data column only. Each slice is labelled with its name and value; on narrow screens, or with more than 6 slices, a legend is used instead. Slices follow the categorical colour order. To set a slice's colour yourself, add it to the slice's row header.

## Changing the colour

Colours follow the categorical order by default. To choose a series' colour yourself, set `colour` on its dataset to a [chart colour](/styles/chart-colours) name. In HTML, add `data-iai-chart-colour` to the series' column header.

## Changing the line style

On line and area charts, lines follow the order solid, dashed, dotted by default. To choose a series' line style yourself, set `line` on its dataset to `"solid"`, `"dashed"` or `"dotted"`. In HTML, add `data-iai-chart-line` to the series' column header.

## Adding a description

Add a `description` to say what the chart shows in a sentence or two, for example the main trend or the biggest value. It appears under the title, and screen readers read it with the chart. In HTML, add a paragraph with the `iai-chart__description` class after the heading.

The title is an `h3` by default. Set `headingLevel` so it fits the headings on your page. In HTML, use any heading element; in web components, use the `heading-level` attribute.

## Changing the size

Line, area, bar and horizontal bar charts fill the width of their container. Pie and doughnut charts are square, so they stop at 600px wide. To change this, set `--iai-chart-max-width` on the chart or on a container. Use `none` to remove the limit.

```html
<div class="iai-chart iai-chart--pie" data-module="iai-chart" style="--iai-chart-max-width: 400px">
```

## Accessibility

### Colour

Do not rely on colour alone. Some people cannot tell colours apart.

- Use colours from the [chart colours](/styles/chart-colours) palette. They are chosen to work together.
- Give each series and slice a clear label.
- Charts with only one series or slice have no legend, so make sure the title says what it shows.
- Use no more than 5 colours in one chart.

### Line styles

On line and area charts, give each series a different line style: solid, dashed or dotted. People can then tell the lines apart without seeing colour, including when printed in black and white.

Bar, horizontal bar, pie and doughnut charts cannot use line styles. Keep these to a few series or slices, and label them clearly.

### Data table

Every chart includes its data as a table, under "Show data".

- Screen readers announce the chart's title and description, and users can open the table to read the values.
- If JavaScript does not load, the table is still there. This does not apply to web components, which need JavaScript.
- Users can read exact values that are hard to judge from the chart.

## Component options

These are the same for Astro, React, Svelte and Solid. For web components, `variant`, `title` and `description` are attributes, `headingLevel` is the `heading-level` attribute, and `data` is JSON in a `<script type="application/json">` inside the element.

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `variant` | `"line"`, `"area"`, `"bar"`, `"horizontal-bar"`, `"pie"` or `"doughnut"` | Yes | The type of chart. |
| `title` | text | Yes | Shown as the heading and the table caption. Screen readers read it as the chart's name. |
| `description` | text | No | A short summary of what the chart shows. Shown under the title, and screen readers read it with the chart. |
| `headingLevel` | `1` to `6` | No | The title's heading level. Defaults to `3`. |
| `data` | object | Yes | The chart's data. See below. |

### `data`

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `heading` | text | Yes | The header of the table's first column, which names the labels. For example, "Month". |
| `labels` | list of text | Yes | The points along the axis, or the slices of a pie. For example, `["January", "February"]`. |
| `datasets` | list of datasets | Yes | One for each series. Pie and doughnut charts use the first dataset only. |

### Each dataset

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `label` | text | Yes | The series name, shown in the legend and as the table column header. |
| `data` | list of numbers | Yes | One value for each label, in the same order. Use `null` to leave a gap. |
| `colour` | a [chart colour](/styles/chart-colours) name, or a list of them | No | One colour for the series. On pie and doughnut charts, a list with one colour for each slice. If not set, colours follow the default order. |
| `line` | `"solid"`, `"dashed"` or `"dotted"` | No | The line style, on line and area charts. If not set, line styles follow the order solid, dashed, dotted. |

### HTML

In plain HTML, set the same options on the markup:

| Option | Where | Example |
| --- | --- | --- |
| Chart type | A class on the outer `div` | `class="iai-chart iai-chart--pie"` |
| Description | A paragraph after the heading | `<p class="govuk-body iai-chart__description">` |
| Heading level | The heading element | `<h2 class="govuk-heading-m">` |
| Series colour | An attribute on the column header | `<th data-iai-chart-colour="blue-shade-50">` |
| Slice colour | An attribute on the row header | `<th scope="row" data-iai-chart-colour="blue">` |
| Line style | An attribute on the column header | `<th data-iai-chart-line="dashed">` |
| Values | The table cells, as numbers | `<td>1,240</td>`. Use `–` or leave empty for a gap. |
| Maximum width | A CSS variable, on pie and doughnut charts | `style="--iai-chart-max-width: 400px"` |
