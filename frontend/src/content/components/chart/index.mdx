## When to use this component

Use a chart when the shape of the data matters more than the exact values, for example a trend over time or a comparison between a few series.

Use colours from the [chart colours](/styles/chart-colours). Do not use colour as the only way to tell series apart: give each series a clear label and, on line, area and radar charts, a different line style (solid, dashed or dotted).

## When not to use this component

Do not use a chart if users need to read or compare exact values. Use a [table](/components/table) instead.

Only use a pie, doughnut or polar area chart for a few parts of one whole, ideally no more than five. People find it hard to compare the size of slices, so a bar chart is usually clearer.

Only use a radar chart for a few series and when every measure uses the same scale. If not, use a bar chart.

## Changing the size

Line, area and bar charts fill the width of their container. Pie, doughnut, polar area and radar charts are square, so they stop at 600px wide. To change this, set `--iai-chart-max-width` on the chart or on a container. Use `none` to remove the limit.

```html
<div class="iai-chart iai-chart--pie" data-module="iai-chart" style="--iai-chart-max-width: 400px">
```

## Accessibility

### Colour

Do not rely on colour alone. Some people cannot tell colours apart.

- Use colours from the [chart colours](/styles/chart-colours) palette. They are chosen to work together.
- Give each series and slice a clear label.
- Use no more than 5 colours in one chart.

### Line styles

On line, area and radar charts, give each series a different line style: solid, dashed or dotted. People can then tell the lines apart without seeing colour, including when printed in black and white.

Bar, pie, doughnut and polar area charts cannot use line styles. Keep these to a few series or slices, and label them clearly.

### Data table

Every chart includes its data as a table, under "Show data".

- Screen readers announce the chart's title, and users can open the table to read the values.
- If JavaScript does not load, the table is still there. This does not apply to web components, which need JavaScript.
- Users can read exact values that are hard to judge from the chart.

## Component options

These are the same for Astro, React, Svelte and Solid. For web components, `variant` and `title` are attributes, and `data` is JSON in a `<script type="application/json">` inside the element.

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `variant` | `"line"`, `"area"`, `"bar"`, `"pie"`, `"doughnut"`, `"radar"` or `"polar-area"` | Yes | The type of chart. |
| `title` | text | Yes | Shown as the heading and the table caption. Screen readers read it as the chart's name. |
| `data` | object | Yes | The chart's data. See below. |

### `data`

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `heading` | text | Yes | The header of the table's first column, which names the labels. For example, "Month". |
| `labels` | list of text | Yes | The points along the axis, or the slices of a pie. For example, `["January", "February"]`. |
| `datasets` | list of datasets | Yes | One for each series. Pie, doughnut and polar area charts use the first dataset only. |

### Each dataset

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `label` | text | Yes | The series name, shown in the legend and as the table column header. |
| `data` | list of numbers | Yes | One value for each label, in the same order. Use `null` to leave a gap. |
| `colour` | a [chart colour](/styles/chart-colours) name, or a list of them | No | One colour for the series. On pie, doughnut and polar area charts, a list with one colour for each slice. If not set, colours follow the default order. |
| `line` | `"solid"`, `"dashed"` or `"dotted"` | No | The line style, on line, area and radar charts. Defaults to `"solid"`. |

### HTML

In plain HTML, set the same options on the markup:

| Option | Where | Example |
| --- | --- | --- |
| Chart type | A class on the outer `div` | `class="iai-chart iai-chart--pie"` |
| Series colour | An attribute on the column header | `<th data-iai-chart-colour="blue-shade-50">` |
| Slice colour | An attribute on the row header | `<th scope="row" data-iai-chart-colour="blue">` |
| Line style | An attribute on the column header | `<th data-iai-chart-line="dashed">` |
| Values | The table cells, as numbers | `<td>1,240</td>`. Use `–` or leave empty for a gap. |
| Maximum width | A CSS variable, on pie, doughnut, polar area and radar charts | `style="--iai-chart-max-width: 400px"` |
