## Default

The default warning text uses a visually hidden fallback of "Warning" for the icon.

<Example optionsHref="#component-options" component="warning-text" html="./examples/default.html" react="./examples/default.react.tsx" svelte="./examples/default.svelte" solid="./examples/default.solid.tsx" />

## When to use this component

Use the warning text component when you need to warn users about something important, such as legal consequences of an action, or lack of action, that they might take.

## Component options

These are the same for React, Svelte and Solid.

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `children` | text | Yes | The warning message. Screen readers announce it with "Warning". |
| `class` | text | No | Adds extra classes to the warning. |
