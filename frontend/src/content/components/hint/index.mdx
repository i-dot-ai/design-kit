## Component options

These are the same for Astro, React, Svelte and Solid.

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `class` | string | No | Added to `govuk-hint` on the `<div>` element. The way to restyle the hint. |
| `children` | text | Yes | The hint text shown alongside the form field. |
