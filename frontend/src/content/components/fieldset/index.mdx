## When to use this component

Use the fieldset component when you need to show a relationship between multiple form inputs. For example, you may need to group a set of text inputs into a single fieldset when [asking for an address in your service](https://design-system.service.gov.uk/patterns/addresses/).

If you’re using the examples or macros for a [Radios component](/components/radios/), [Checkboxes component](/components/checkboxes/) or [Date input component](/components/date-input/), the fieldset will already be included.

## Component options

These are the same for React, Svelte and Solid.

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `class` | string | No | Added to `govuk-fieldset` on the `<fieldset>` element. The way to restyle the fieldset as a whole. |
| `children` | text | Yes | The legend and the grouped form inputs. The legend is a separate component with its own size and page heading options. |
