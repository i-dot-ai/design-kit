## When to use this component

Use this footer when building a product that is for i.AI or another department in
government, alongside the [generic header](/components/header).

This footer is the default. An experimental product, or one whose audience is not
yet settled, starts with this footer and can switch to the [GOV.UK
footer](/components/govuk-footer) later.

## When not to use this component

Do not use the generic footer for a public-facing or cross-government service. Use
the [GOV.UK footer](/components/govuk-footer) instead so the product reads as
GOV.UK.

## Component options

These are the same for React, Svelte and Solid.

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `links` | array of objects | No | Support links shown in the inline list, for example Accessibility statement, Cookies and Privacy. Each link takes `href`, `text` and `attributes`. |
| `visuallyHiddenTitle` | text | No | Visually hidden heading above the support links. Defaults to `Support links`. |
| `containerClasses` | string | No | Extra classes for the width container that wraps the footer content. |
| `class` | string | No | Added to `govuk-footer` on the `<footer>` element. The way to restyle the footer. |
