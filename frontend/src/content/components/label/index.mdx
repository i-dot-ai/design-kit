## Component options

These are the same for Astro, React, Svelte and Solid.

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `size` | `"small"`, `"medium"`, `"large"` or `"xl"` | No | The label's size. Adds the matching size modifier, for example `govuk-label--m`. |
| `isPageHeading` | boolean | No | Wraps the label in an `<h1>` so it acts as the page heading. |
| `class` | string | No | Added to `govuk-label` on the `<label>` element. The way to restyle the label. |
| `children` | text | Yes | The label text shown above or beside the form field. |
