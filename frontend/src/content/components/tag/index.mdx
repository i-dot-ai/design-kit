## When to use this component

Use the Tag component when it’s possible for something to have more than one status and it’s useful for the user to know about that status. For example, you can use a tag to show whether an item in a [Task list component](/components/task-list/) has been ‘completed’.

## Component options

These are the same for React, Svelte and Solid.

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `colour` | `"grey"`, `"green"`, `"teal"`, `"turquoise"`, `"blue"`, `"light-blue"`, `"purple"`, `"magenta"`, `"pink"`, `"red"`, `"orange"` or `"yellow"` | No | The tag's colour. Adds the matching modifier class. |
| `children` | text | Yes | The status text, for example "Active". |
| `class` | text | No | Adds extra classes to the tag. |
