## Default

Add the product name and the i.AI logo to the header.

The header landmark is intentionally left out of the component so that you can add 
other components such as phase banner or service navigation to the header landmark.

<Example component="header" html="./examples/default.html" astro="./examples/default.astro" react="./examples/default.react.tsx" svelte="./examples/default.svelte" solid="./examples/default.solid.tsx" />

## When to use this component

Use this header when building a product that is for i.AI or another department in 
government.

This header is the default. An experimental product, or one whose
audience is not yet settled, starts with this header and can switch to the
[GOV.UK header](/components/govuk-header) later.

## When not to use this component

Do not use the generic header for a public-facing or cross-government service. Use
the [GOV.UK header](/components/govuk-header) instead so the product reads as
GOV.UK.
