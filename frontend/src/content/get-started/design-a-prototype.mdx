You can use an AI agent to prototype with the i.AI Design Kit by using the skill file below. The file has been tested with Claude, but should work with other AI agents.

## Add the skill 

To add the skill to Claude:

1. <a
    class="govuk-link"
    href="/downloads/iai-prototype-skill.zip"
    download="iai-prototype-skill.zip">Download this zipped skill file</a>
2. From the left menu of [Claude.ai](https://claude.ai), click the Customize section
3. From the top-right menu, click Add and then Upload skill
4. Upload the zipped skill file you downloaded in step 1 and click save

## Use the skill

To use the skill, type `/iai-prototype` into Claude and hit enter.
