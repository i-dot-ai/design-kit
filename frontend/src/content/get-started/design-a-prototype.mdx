There are 3 ways to use the i.AI prototype skill. Choose the one that fits how you work.

- [Use Claude.ai in your browser](#use-claudeai-in-your-browser)
- [Use the skill in an IDE with Claude Code or OpenCode](#use-the-skill-in-an-ide-with-claude-code-or-opencode)
- [Use the GOV.UK Prototype Kit](#use-the-govuk-prototype-kit)

## 1. Use Claude.ai in your browser

This is the quickest way to get started. You do not need a coding environment.

<h3 class="govuk-heading-m govuk-!-margin-top-7">Add the skill</h3>

1. <a
    class="govuk-link"
    href="/downloads/iai-prototype-skill.zip"
    download="iai-prototype-skill.zip">Download the skill file</a>
2. Go to [Claude.ai](https://claude.ai) and open the left menu
3. Select **Customize**, then from the top-right menu select **Add** and **Upload skill**
4. Upload the file you downloaded and select **Save**

<h3 class="govuk-heading-m govuk-!-margin-top-7">Use the skill</h3>

Type `/iai-prototype` into Claude and press enter.

<h3 class="govuk-heading-m govuk-!-margin-top-7">Edit the skill</h3>

You can edit the skill in the Customize section of Claude.ai.

<h2 class="govuk-heading-l govuk-!-margin-top-9" id="use-the-skill-in-an-ide-with-claude-code-or-opencode">Use the skill in an IDE with Claude Code or OpenCode</h2>

Use this approach if you are already working in VS Code, Cursor, or another IDE with Claude Code or OpenCode set up.

<h3 class="govuk-heading-m govuk-!-margin-top-7">Get the skill</h3>

The i.AI prototype skill is available from the [i.Ai skills repository](https://github.com/i-dot-ai/skills-and-projects/tree/main/skills)

<h3 class="govuk-heading-m govuk-!-margin-top-7">Use the skill</h3>

Follow the instructions in the repository you chose to add the skill to your IDE. Then type `/iai-prototype` to trigger the skill.

<h2 class="govuk-heading-l govuk-!-margin-top-9" id="use-the-govuk-prototype-kit">Use the GOV.UK Prototype Kit</h2>

Use this approach if you are working in the [GOV.UK Prototype Kit](https://prototype-kit.service.gov.uk/docs/) and want to use AI assistance to generate pages.

The GOV.UK Prototype Kit lets you build interactive prototypes that look and feel like GOV.UK pages. You can use it for design work and user research.

<h3 class="govuk-heading-m govuk-!-margin-top-7">Before you start</h3>

You need to have the GOV.UK Prototype Kit installed and running. If you have not set it up yet, follow the [getting started guide](https://prototype-kit.service.gov.uk/docs/install/introduction) on the Prototype Kit site.

You also need Claude Code or OpenCode set up in your IDE.

<h3 class="govuk-heading-m govuk-!-margin-top-7">Add the skill</h3>

1. <a
    class="govuk-link"
    href="/downloads/iai-prototype-skill.zip"
    download="iai-prototype-skill.zip">Download the skill file</a> and unzip it. You'll get a folder called iai-prototype containing a SKILL.md file.
2. Open your prototype's root folder in your IDE. This is the folder you created with the Prototype Kit, the one containing package.json, app and node_modules.
3. Open your IDE's terminal. The prompt should show your prototype's name. If it doesn't, use cd to move into your prototype's root folder.
4. Create the skills folder and open it in Finder.

   For Claude Code, run:

   <CodeBlock collection="get-started" component="design-a-prototype" code="./examples/claude-skills-folder.sh" />

   For OpenCode, run:

   <CodeBlock collection="get-started" component="design-a-prototype" code="./examples/opencode-skills-folder.sh" />

   The command will not print anything in the terminal, but a Finder window will open. The folder is hidden because its name starts with a dot, so you won't see it in your IDE's file list or in Finder.

5. Copy the unzipped iai-prototype folder into the Finder window(s). 
The skill file should now be at:

<CodeBlock collection="get-started" component="design-a-prototype" code="./examples/claude-skill-path.txt" /> 
or

<CodeBlock collection="get-started" component="design-a-prototype" code="./examples/opencode-skill-path.txt" />

6. Start a new Claude Code or OpenCode conversation in your IDE. 

<h3 class="govuk-heading-m govuk-!-margin-top-7">Use the skill</h3>

Type `/iai-prototype` to trigger the skill. The skill will generate pages inside your prototype kit project, which you can preview in your browser using the kit's local server.

To run the local server, open a terminal in your project folder and run:

<CodeBlock collection="get-started" component="design-a-prototype" code="./examples/npm-run-dev.sh" /> 

Then go to `http://localhost:3000` in your browser to preview your prototype.
