This is a community resource and we encourage and appreciate all contributions. You can contribute by:

- [adding a style, component or pattern](#add-a-style-component-or-pattern)
- [adding a skill](#add-a-skill)
- [contacting us on Slack](#contact-us-on-slack)

## Add a style, component or pattern

You can add a style, component or pattern by submitting a request which explains what you'd like to see and why. Find [how to write a contribution](https://github.com/i-dot-ai/design-kit/blob/main/CONTRIBUTING.md).

To suggest a contribution:

- open a pull request against the [design kit repository](https://github.com/i-dot-ai/design-kit)
- add details about the changes you need and why

You do not need to be detailed. For example, you could submit a:

- request for use case
- variation for an existing component
- decision record of changes you made
- full component with all its tests

> You can keep using your component while we review your submission. We will contact you if we add the component to the i.AI Design Kit so you can update your code.

### What happens next

When you submit a request for a component change, we will review it to make sure it meets standards for:

- technical code (maintainability)
- accessibility
- design approaches

If it doesn't meet these standards we may ask for changes. If you can't make these yourself we can take over iteration, but this may take longer to publish.

When the component is ready we will update the i.AI Design Kit and announce it on our Slack channel.

If your contribution isn't accepted, we'll explain why in the pull request.

## Add a skill

We are improving how we build and share skills. If you have a suggestion for skills updates please contact us on [#iai-design-kit](https://i-dot-ai.slack.com/archives/C0C476E1D4H).

## Contact us on Slack

Get in touch on [#iai-design-kit](https://i-dot-ai.slack.com/archives/C0C476E1D4H) for everything to do with the i.AI Design Kit, for example:

- questions about how to get started
- questions about a contribution PR
- issues in the kit
- confusion in the guidance
