title: Adapt an existing product
description: For bringing a product onto the kit for the first time.
---

You can use the i.AI Design Kit on existing products.

To do this you need to:

1. [Install frontend styles and scripts.](#1-install-frontend-styles-and-scripts)
2. [Link to CSS and JavaScript.](#2-link-to-css-and-javascript)
3. [Add the component library.](#3-add-the-component-library)
4. [Record design decisions.](#4-record-design-decisions)

## 1. Install frontend styles and scripts

Install Sass, govuk-frontend and i.AI amended frontend:

<CopyableCode code="npm install sass govuk-frontend @i-dot-ai-npm/component-library-frontend --save" />

Create a idotai.scss file and copy this into it:

<CopyableCode code={`// GOV.UK Frontend, compiled without GOV.UK branding.
// See: https://frontend.design-system.service.gov.uk/using-govuk-frontend-without-govuk-branding/
//
// The i.AI brand values come from the kit, so they stay in step with it.
@use "@i-dot-ai-npm/component-library-frontend/settings" as iai;
@use "govuk-frontend" as * with (
  $govuk-font-family: iai.$iai-font-family,
  $govuk-functional-colours: iai.$iai-functional-colours
);

// i.AI override layer — must come after govuk-frontend's base styles.
@use "@i-dot-ai-npm/component-library-frontend/css";`} />

This is the recommended way to adapt GOV.UK Frontend for services that
are not on the gov.uk domain. There is more on this in the
[using GOV.UK Frontend without GOV.UK branding guide](https://frontend.design-system.service.gov.uk/using-govuk-frontend-without-govuk-branding/#updating-your-sass-to-remove-branded-elements).


If your product is department-branded, this is where the department's
colour goes. Check it passes contrast on white surfaces before you set
it.

## 2. Link to CSS and JavaScript

Link to the idotai.scss file in your main layout. In Astro this will be in the layout.astro file.

In Astro:

<CopyableCode code={`---
import '<path-to-styles>/idotai.scss'
---`} />

In html:

<CopyableCode code={`<head>
    ...
    <link rel="stylesheet" href='<path-to-styles>/idotai.scss' />
    ...
</head>`} />



After the closing body tag, import <code class="app-code">initAll</code> from govuk-frontend and
<code class="app-code">initAllIAIDesignSystem</code> from the i.AI JavaScript file:

<CopyableCode code={`<body>
    ...
        <script>
            import { initAll } from "govuk-frontend";
            import { initAllIAIDesignSystem } from '@i-dot-ai-npm/component-library-frontend';
            initAll();
            initAllIAIDesignSystem();
        </script>
    <body>
</html>`} />

## 3. Add the component library

Review each component against the ones in the i.AI Design Kit component library. For each one:

1. If there's an existing equivalent component, replace your original.
2. If you think your version provides value, see if you can modify an existing component.
3. If there isn't, record your design decisions.

## 4. Record design decisions

We need your help to improve the i.AI Design Kit. Record your actions and justification if you:

- added a component to the kit
- changed any process or component
- noticed anything missing
- found anything confusing

Please [let us know what you changed and why](/get-started/contribute-to-the-design-kit).
