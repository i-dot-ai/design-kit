Use this when starting any project in i.AI.

## Start with the i.AI Cookie Cutter

Follow the instructions for setting up a new project
in the [i.AI Cookie Cutter repository](https://github.com/i-dot-ai/i-dot-ai-cookiecutter).

The cookie cutter has been set up with the i.AI Design Kit fully integrated.

## Use the i.AI Design Kit Build skill

Use the [i.AI Design Kit Build skill](https://github.com/i-dot-ai/skills-and-projects/blob/main/skills/design-kit-build/SKILL.md) to build a product interface using the i.AI Design Kit. The skill will guide you through the process of building a product interface using the i.AI Design Kit.


## Choose a product brand

Using the Design Kit, products can be branded as GOV.UK, a department, or as an i.AI product. It's easy to switch between brands later. We recommend starting with the i.AI brand for new products, unless you already know what brand will be required.

To apply a specific brand to a product, you will need to:

- Add the brand's header and footer components to pages
- Set the global font and colour schme for the brand

Read this guide on [choosing the right brand for your product](styles/branding)

## Use styles, components and patterns from the Design Kit

Whether you are building using AI or not, you should work within the i.AI Design Kit. It has been designed to free up design decisions so that you can focus on important and challenging user experience questions.

## Share any pain points you encounter
If you do encounter issues with the Design Kit, let us know on Slack. Similarly, if you encounter design pain points which have not been solved for then you can share your [solutions with the Design Kit](/get-started/contribute-to-the-design-kit) so that others can benefit from them.
