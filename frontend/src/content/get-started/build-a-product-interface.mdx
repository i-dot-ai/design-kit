The [i.AI Cookie Cutter](https://github.com/i-dot-ai/i-dot-ai-cookiecutter) is a terminal-based template which helps you create projects, and uses the i.AI Design Kit. You should use this when you start to build a project. To do this you need to:

1. [Set up the i.AI Cookie Cutter.](#set-up-the-iai-cookie-cutter)
2. [Use the i.AI Design Kit Skill.](#use-the-iai-design-kit-skill)
3. [Choose a product brand.](#choose-a-product-brand)
4. [Use the Design Kit to build your product.](#use-the-design-kit-to-build-your-product)

## Set up the i.AI Cookie Cutter

Follow the [instructions to set up a new project](https://github.com/i-dot-ai/i-dot-ai-cookiecutter/blob/main/README.md).

## Use the i.AI Design Kit Skill

You can use the [i.AI Design Kit Build skill](https://github.com/i-dot-ai/skills-and-projects/blob/main/skills/design-kit-build/SKILL.md) in the Cookie Cutter to build a product interface.


## Choose a product brand

You can brand your product with:

- i.AI branding
- GOV.UK branding
- a department's branding

Find out how to [choose the right brand for your product](styles/branding). If you are unsure, use i.AI branding.

## Use the Design Kit to build your product

The design kit has been designed to simplify design decisions so you can focus on creating and improving the user experience.

## Questions and issues

If you have any issues, contact us on the [#iai-design-kit](https://i-dot-ai.slack.com/archives/C0C476E1D4H) channel.

You can also [suggest or request new content](/get-started/contribute-to-the-design-kit) for the design kit.
