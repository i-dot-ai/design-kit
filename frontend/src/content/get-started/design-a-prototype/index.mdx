Use the i.AI Design Kit when you design a prototype to make sure it follows best practice. To do this you can either:

- point your coding agent to the [design-kit-repo](https://github.com/i-dot-ai/design-kit/tree/main/frontend/src/content)
- use the Design Kit Prototype skill

The Design Kit Prototype skill reads this site and creates a prototype as a single HTML file. You can use the skill with:

- [Claude in your browser](#use-the-skill-with-claude-in-your-browser)
- [an IDE](#use-the-skill-with-an-ide) (for example, Claude Code or OpenCode)
- the [GOV.UK Prototype Kit](#use-the-skill-with-the-govuk-prototype-kit)

## Use the skill with Claude in your browser

To add the skill to Claude:

1. <a
    class="govuk-link"
    href="/downloads/design-kit-prototype-skill.zip"
    download="design-kit-prototype-skill.zip">Download the skill file</a>.
2. Go to [Claude.ai](https://claude.ai).
3. In the sidebar, select **Customize**.
4. Select **+ Add**.
5. Select **Upload skill**.
6. Select the file you downloaded.
7. Select **Save**.

### Edit the skill

To edit the skill:

1. Go to [Claude.ai](https://claude.ai).
2. In the sidebar, select **Customize**.
3. Select the **Yours** tab.
4. Under Created by you, select **design-kit-prototype**.
5. Select the **Contents** tab.
6. Select **Edit**.
7. Select **Save**.

If you think others would benefit from your changes, raise a pull request on GitHub and we will review them.

## Use the skill with the GOV.UK Prototype Kit

Use this if you work in the [GOV.UK Prototype Kit](https://prototype-kit.service.gov.uk/docs/) and want to use AI to create pages which look like GOV.UK. Use it for design and user research.

### Before you start

You need to have the GOV.UK Prototype Kit installed and running. If you have not set it up yet, follow the [getting started guide](https://prototype-kit.service.gov.uk/docs/install/introduction) on the Prototype Kit site.

You also need Claude Code or OpenCode set up in your IDE.

### Add the skill

1. <a
    class="govuk-link"
    href="/downloads/design-kit-prototype-skill.zip"
    download="design-kit-prototype-skill.zip">Download the skill file</a>.
2. Unzip the file. You will get a design-kit-prototype folder containing a SKILL.md file.
3. Open your prototype's root folder in your IDE. This is the folder you created with the Prototype Kit, the one containing package.json, app and node_modules.
4. Open your IDE's terminal. The prompt should show your prototype's name. If it doesn't, use cd to move into your prototype's root folder.
5. Create the skills folder and open it in Finder.

   For Claude Code, run:

   <CopyableCode code="mkdir -p .claude/skills && open .claude/skills" />

   For OpenCode, run:

   <CopyableCode code="mkdir -p .opencode/skills && open .opencode/skills" />

   The command will not print anything in the terminal, but a Finder window will open. The folder is hidden because its name starts with a dot, so you won't see it in your IDE's file list or in Finder.

6. Copy the unzipped design-kit-prototype folder into the Finder window(s). 
7. Start a new Claude Code or OpenCode conversation in your IDE. 

### Use the skill

Type <code class="app-code">/design-kit-prototype</code> to trigger the skill. The skill will generate pages inside your prototype kit project, which you can preview in your browser using the kit's local server.

To run the local server, open a terminal in your project folder and run:

<CopyableCode code="npm run dev" /> 

Then go to [http://localhost:3000](http://localhost:3000) in your browser to preview your prototype.
