Use the Design Kit when you design a prototype to make sure it follows best
practice. To do this you can either:

- point your coding agent to the
  [design kit content](https://github.com/i-dot-ai/design-kit/tree/main/frontend/src/content)
- use the community [Design Kit skills](/get-started/use-the-design-kit-skills)

## Prototype as a single HTML page

The `design-kit-html-page` skill builds a prototype as a single self-contained
HTML file, which you can open in your browser and share. It uses the guidance
from the `read-design-kit` skill, so install both.

1. [Install the skills in OpenCode](/get-started/use-the-design-kit-skills).
2. Start a new OpenCode conversation and mention both skills in your message
   with `@read-design-kit` and
   `@design-kit-html-page`, for example:

   ![screenshot showing the @read-design-kit and @design-kit-html-page skills in an opencode terminal with instructions to design a prototype](/images/Screenshot-opencode-design-kit-html.webp)


   <CodeBlock collection="get-started" component="design-a-prototype" code="./examples/skill-command.sh" />

3. The agent reads the latest guidance from this site and builds the prototype
   as a single HTML file. Open it in your browser to view it.

Make one change at a time and save each version of the file so you can compare
them. Find out how we used this approach to rebuild Parlex as a clickable
prototype in [in practice](/in-practice/parlex).

## Use the Design Kit guidance in the GOV.UK Prototype Kit

Use this if you work in the
[GOV.UK Prototype Kit](https://prototype-kit.service.gov.uk/docs/) and want AI
to create pages that look like GOV.UK. Use it for design and user research.

To do this you need to have the Prototype Kit installed and OpenCode set up in
your IDE. If you have not set up the kit yet, follow the
[getting started guide](https://prototype-kit.service.gov.uk/docs/install/introduction)
on the Prototype Kit site.

1. [Install the `read-design-kit` skill in OpenCode](/get-started/use-the-design-kit-skills).
   A global install makes it available in your prototype project too.
2. Start a new OpenCode conversation in your IDE, mention the skill in your
   message with `@read-design-kit` and ask for the
   pages you need, for example:

   <CodeBlock collection="get-started" component="design-a-prototype" code="./examples/prototype-kit-command.sh" />

3. Preview your pages in your browser using the kit's local server. Open a
   terminal in your project folder and run:

   <CodeBlock collection="get-started" component="design-a-prototype" code="./examples/npm-run-dev.sh" />

Then go to [http://localhost:3000](http://localhost:3000) in your browser to
preview your prototype.
