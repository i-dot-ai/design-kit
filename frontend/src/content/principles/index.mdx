## Designing products

When designing products in i.AI:

- follow the [UK Government Design Principles](https://www.gov.uk/guidance/government-design-principles)
- use the styles, components and patterns in the i.AI Design Kit
- use these [design heuristics](/principles/design-heuristics) to help you make design decisions

## Creating new components and patterns

Where a user need is not met by the Design Kit, you can create your own component or pattern, but it should be consistent with the styles in the Kit.

If you do create a new component or pattern, consider [contributing it back to the i.AI Design Kit](/get-started/contribute-to-the-design-kit) so that it can be used by other teams.
