## Pain point

This pattern was developed in both the [extract planning 
app](https://github.com/i-dot-ai/extract-app/) and 
[Minute](https://github.com/i-dot-ai/minute/). In both cases there was 
was a need to search and filter a long list of results in a table on the page


## Solution

The arrived at pattern was to build a search and filter wrapper with the search field
and filter option using the [summary table pattern](/patterns/summary-table) for the 
results.

**Note:** The search or filter hasn't been implemented in the example, just the design.

### When to use this pattern

Use a summary table when:

-   users need to search, filter or manage a large list of items in a table below
